# AI Mathematics for ML — Mathematical Foundations

**Project:** AI-001 Mathematics for AI Engineering  
**Domain:** D01 — Mathematics, Statistics and Probability  
**Curriculum:** Mathematical Foundations v1.0

## Objective
Build the mathematical foundations required to understand, derive and implement mathematics used in Machine Learning, Deep Learning, NLP and LLM engineering.

## Study order

1. Algebraic Foundations — `01_Algebraic_Foundations/010-algebraic-expressions-and-equations.ipynb`
2. Functions — `02_Functions/020-functions-and-mathematical-relationships.ipynb`
3. Exponents — `03_Exponents/030-exponents-and-powers.ipynb`
4. Logarithms — `04_Logarithms/040-logarithms-and-ai-ml-applications.ipynb`
5. Mathematical Notation and Reasoning — `05_Mathematical_Notation/050-mathematical-notation-and-reasoning.ipynb`
6. Essential Trigonometry — `06_Trigonometry/060-essential-trigonometry.ipynb`

## How to study
- Read theory and reconstruct derivations manually.
- Run code cells from top to bottom.
- Attempt practice problems without copying examples.
- Record uncertainties for the later competency test.
- Do not equate notebook completion with demonstrated mastery.

## Environment
Python 3.10+ recommended.

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Open notebooks with JupyterLab, Jupyter Notebook or a compatible editor.

## Scope boundaries
These notebooks cover foundational mathematics and selected AI/ML connections. Detailed Linear Algebra, Calculus, Probability and Statistics, Optimisation, Classical ML, Deep Learning and Transformer mathematics are covered in their dedicated learning threads.
